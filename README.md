# Chappi Edition — Учёт столбов

Новая версия системы учёта производства столбов 60×40. Проект начинается с чистого репозитория, но опирается на накопленные требования и уроки предыдущих версий.

## Цели

- Ежедневный учёт фактического производства по длинам.
- Учёт бригад, работников и рабочего времени.
- Исторические расценки и проверяемый расчёт заработка.
- Заказы, очередь, выполнение частями и автоматическое завершение.
- Складской учёт через движения продукции.
- Отгрузки, отчёты, архив и журнал изменений.
- Резервное копирование и восстановление.

## Принципы

1. Данные не должны теряться при изменении функций.
2. Исторические операции сохраняют исходные характеристики и применённые расценки.
3. Склад рассчитывается из зарегистрированных движений, а не из произвольного ручного остатка.
4. Важные изменения журналируются.
5. Финансовые расчёты должны быть воспроизводимыми и проверяемыми.
6. Неясные правила производства и оплаты фиксируются как вопросы, а не угадываются.
